Bonnes pratiques en Data Science

Pandas est optimisé pour le calcul vectorisé. Éviter les boucles et enchaîner les méthodes rend le code plus rapide et plus lisible.

boucle — lent

resultats = [] for note in df['note']: resultats.append(note * 1.1) df['note_maj'] = resultats

vectorisé — rapide

df['note_maj'] = df['note'] * 1.1

method chaining — un pipeline lisible

résultat = ( df .dropna() .query('age > 18') .assign(mention=lambda d: d['note'] >= 14) .sort_values('note', ascending=False) )
